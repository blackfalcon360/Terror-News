# Terror News

X (Twitter) کی عوامی ٹائم لائنز سے دہشت گردی کی خبریں — فاٹا/باجوڑ اور پوری دنیا۔ لاگ اِن کی ضرورت نہیں۔

## ایپ کیا کرتی ہے
- ٹیبز: سب، فاٹا/باجوڑ، ٹی ٹی پی، داعش/ISKP، طالبان، سیٹنگز۔
- کی ورڈز: Bajaur, TTP, IS, ISKP, Taliban, IMU, IMP, Daesh, Khorasan وغیرہ (سیٹنگز میں تبدیل ہو سکتے ہیں)۔
- ہر خبر پر ٹیپ کریں تو لنک ایپ کے اندرونی براؤزر (WebView) میں کھلتا ہے۔
- زبان: اردو / English / العربية (اردو و عربی دائیں سے بائیں)۔
- سیٹنگز میں لائٹ اور ڈارک موڈ، X اکاؤنٹس کی فہرست، کی ورڈز۔
- باہر نکلتے وقت تصدیق کا ڈائیلاگ۔

## بِلڈ
1. پوری فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions ٹیب میں "Build APK" چلے گا۔
3. مکمل ہونے پر Artifacts سے `TerrorNews-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait۔ AndroidX یا کوئی بیرونی لائبریری نہیں۔
- X کا سرکاری API نہیں؛ عوامی embed/syndication ٹائم لائنز پڑھی جاتی ہیں۔ X انہیں کسی وقت بند یا محدود کر سکتا ہے۔
- X پر کیورڈ سرچ بغیر لاگ اِن ممکن نہیں، اس لیے اکاؤنٹس کی فہرست سے ٹویٹس لے کر کی ورڈز سے چھانٹی جاتی ہے۔
- X سے 5 سے کم پوسٹس ملیں تو بیک اپ کے طور پر Google News کی ہیڈلائنز دکھائی جاتی ہیں۔
- انٹرنیٹ لازمی ہے (صرف INTERNET پرمیشن)۔
